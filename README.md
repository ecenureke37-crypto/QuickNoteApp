# QuickNote — Mini Sprint

Bu proje, React Native CLI kullanılarak geliştirilmiş minimalist bir not alma uygulamasıdır. Kullanıcıların hızlıca not ekleyebileceği, listeleyebileceği ve detaylarını görüntüleyebileceği 3 temel ekrandan oluşmaktadır.

## 📱 Ekranlar ve Özellikler
* **Home:** Kayıtlı notların listelendiği (FlatList ile) ve yeni not ekleme sayfasına yönlendiren ana ekran.
* **Add Note:** Kullanıcının başlık ve içerik girerek yeni bir not oluşturabildiği ekran.
* **Note Detail:** Seçilen notun tam içeriğinin okunduğu detay ekranı.

## 🚀 Kurulum ve Çalıştırma

Projeyi yerel ortamınızda çalıştırmak için aşağıdaki adımları izleyin:

1. **Projeyi Klonlayın:**
   ```bash
   git clone [https://github.com/ecenureke37-crypto/QuickNoteApp.git](https://github.com/ecenureke37-crypto/QuickNoteApp.git)
   cd QuickNoteApp
   ```
2. **Bağımlılıkları Yükleyin:**
   ```bash
   npm install
   ```
 3. **Uygulamayı Başlatın (Android):
    Öncelikle Android emülatörünüzün açık olduğundan emin olun, ardından terminalde şu komutu çalıştırın:**
    ```bash
    npx react-native run-android
    ```
    Kullanılan Teknolojiler
    
   * React Native CLI

   * React Navigation

   * React Hooks (useState)
